
# 크로노블레이드 - 타이밍 기반 콤보 시스템 설명서

## 시스템 개요
이 시스템은 리듬 게임처럼 일정한 박자에 맞춰 공격 입력을 수행하면 보너스를 주는 "타이밍 기반 콤보 전투 시스템"입니다.  
일정 간격(비트)에 맞춰 공격 키를 누르면 `Perfect / Good / Miss` 판정을 하며, 입력한 공격 시퀀스가 특정 콤보 패턴과 일치하면 콤보 공격 상태로 진입합니다.

## 구성 요소

### 1. `TimingComboManager.cs`
- 일정한 박자(`beatInterval`)에 따라 `OnBeat` 이벤트를 발생시킴
- 입력 시간을 저장하여 비트에 얼마나 가까운 타이밍인지 판정
- 판정 결과는 `TimingJudgement` 구조체로 전달되며, 데미지 배율 포함
- 디버그용으로 `isPerfectTiming` 계산 포함

### 2. `ComboEvaluator.cs`
- 공격 입력을 비트 단위로 기록하는 `beatInputBuffer` 사용
- 등록된 콤보와 비교하여 일치 시 `OnComboMatched` 이벤트 발생
- 콤보 실행 중에는 입력 기록 일시 중단
- 각 콤보 단계가 유효한 입력인지 확인하는 `IsValidStep()` 함수 포함

### 3. `PlayerComboState.cs`
- 콤보가 매칭되면 진입하는 FSM 상태
- 매 비트 간격으로 다음 공격을 자동 재생
- 입력 시퀀스가 다르면 콤보 중단
- 콤보 실행 시 `StartComboExecution()`, 종료 시 `EndComboExecution()` 호출

## 핵심 로직 흐름

1. 플레이어가 Light 또는 Heavy 공격 키 입력 → `ComboEvaluator.RegisterInput()` 호출
2. `TimingComboManager`가 `OnBeat` 이벤트 발생 → `ComboEvaluator`가 콤보 매칭 시도
3. 일치하는 콤보가 있으면 `PlayerComboState`로 전이되어 공격 시작
4. 각 타는 `beatInterval`에 따라 자동 진행되며 입력과 다르면 종료
5. 콤보 종료 시 입력 버퍼 초기화 및 이동 상태 복귀

## 커스터마이징 가능 포인트

- `beatInterval` 값을 조정하여 BPM 변경 가능
- `perfectWindow`, `goodWindow` 값을 통해 판정 기준 조절
- 콤보 시퀀스는 `ScriptableObject(ComboSequence)`로 구성되어 손쉽게 추가/수정 가능
- 데미지 보정 배율(`perfectBonusMultiplier` 등)을 통해 타이밍 보상의 강도 설정 가능

## 시각 디버깅

- `TimingComboManager.isPerfectTiming`을 통해 퍼펙트 타이밍 여부 시각화 가능
- `ComboEvaluator`는 현재 입력 상태 및 콤보 진행 상황을 로그로 출력

## 요약

Unity의 Coroutine, FSM, ScriptableObject, 이벤트 시스템을 유기적으로 활용하였으며,  
확장성과 디버깅 편의성을 고려하여 구조화되었습니다.
