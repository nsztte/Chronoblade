
# Chronoblade 입력 시스템 설명서

이 문서는 크로노블레이드 프로젝트에서 사용하는 입력 구조 및 InputManager의 설계를 정리한 문서입니다.

---

## 전체 구조 요약

| 컴포넌트            | 역할                                    |
|--------------------|-------------------------------------|
| InputManager     | 모든 입력을 감지하고 이벤트로 발행하는 클래스 |
| PlayerController   | `이동`, `점프`, `공격` 등 실행 로직 담당 |
| CameraController | 마우스 시점 회전 처리 |

---

## InputManager.cs

싱글톤(Singleton) 기반의 입력 이벤트 발행자입니다.  
플레이어 입력을 모두 감지하여, 각 기능에 대응되는 이벤트를 호출합니다.

---

## 입력 이벤트 목록

| 입력 | 이벤트 이름 | 설명 |
|------|-------------|------|
| WASD 이동 | `OnMoveInput(Vector2)` | `x`: 좌/우, `y`: 전/후 방향 |
| 마우스 이동 | `OnLookInput(Vector2)` | `x`: 좌우 회전, `y`: 상하 회전 |
| Space | `OnJumpPressed()` | 점프 트리거 |
| Shift(눌렀을 때) | `OnRunStarted()` | 달리기 시작 |
| Shift(뗐을 때) | `OnRunCanceled()` | 달리기 종료 |
| Ctrl | `OnCrouchPressed()` | 웅크리기 |
| 좌클릭(클릭) | `OnAttackPressed()` | 원거리 무기용 단일 공격 입력 |
| 좌클릭(유지) | `OnAttackHeld()` | 연사/차징 공격 등 |
| 좌클릭(떼었을 때) | 아래 조건에 따라 분기 |
| └ duration < 0.2s | `OnLightAttackPressed()` | 근접 무기 약 공격 |
| └ duration >= 0.2s | `OnHeavyAttackPressed()` | 근접 무기 강 공격 |
| R | `OnReloadPressed()` | 탄창 재장전 |
| 우클릭(눌렀을 때) | `OnAimStarted()` | 조준 상태 진입 |
| 우클릭(뗐을 때) | `OnAimCanceled()` | 조준 상태 해제 |
| 숫자키 1~4 | `OnWeaponSwitch(int)` | 해당 인덱스 무기로 전환 |
| 마우스 휠 | 내부에서 무기 인덱스 순환 | 이미 장착된 무기면 해제 |
| F | `OnInteract()` | 상호작용 키 (문, 아이템 등) |

## 무기 공격 입력 분기 처리

// 마우스 버튼 Down
attackKeyDownTime = Time.time;

// 마우스 버튼 Up
float duration = Time.time - attackKeyDownTime;
if (duration < LIGHT_ATTACK_THRESHOLD)
    OnLightAttackPressed?.Invoke(); // 짧은 클릭 → 약 공격
else
    OnHeavyAttackPressed?.Invoke(); // 긴 클릭 → 강 공격
```

- `LIGHT_ATTACK_THRESHOLD`: 현재는 `0.2초`로 설정
- 근접 무기에서 공격 강도를 입력 지속 시간으로 구분

---

## 무기 전환 처리

- 숫자 키: 1~4번 → 직접 무기 선택
- 마우스 휠: 이전/다음 무기 순환
- 이미 장착된 무기를 선택할 경우 → `UnEquipWeapon()` 실행

---

## 구조적 장점

- **입력 → 이벤트 발행** → 구독자(예: FSM 상태)에서 처리
- **기능 분리**: 이동, 공격, 무기 전환 등은 각 클래스에서 구체적으로 해석
- **확장 용이**: 새로운 키 입력 추가 시 `InputManager`에만 등록하면 됨
- **테스트 용이**: 단위 테스트 및 디버깅 시 이벤트 기반으로 확인 가능

---

## 향후 확장 계획

| 기능 | 이벤트 |
|------|--------|
| 시간 정지 | `OnTimeStopPressed()` |
| 시간 되감기 | `OnTimeRewindPressed()` |
| 대화 넘기기 | `OnDialogueAdvance()` |
| UI 토글 | `OnInventoryToggle()`, `OnMapToggle()` 등 |

---

## 결론

InputManager는 Chronoblade의 모든 입력을 처리하는 "중앙 허브 역할"을 하며,  
FSM 및 각 기능 스크립트들은 해당 이벤트만 구독하여 "입력과 로직을 완전히 분리"합니다.  
이 구조는 확장성과 유지보수 측면에서 매우 효율적입니다.
